# Verified product facts for the Claude guide series

This file is the source of truth for every fact used anywhere in the "Becoming a Claude Power User" episodes: Anthropic plan prices, model names, setting names, menu paths and toggle behaviour, plus the non-Anthropic facts (credit bureaus, IRS, carriers, device makers) Episode 4 relies on. Each fact carries the exact source it was checked against and the date of that check, so a claim in an episode can always be traced back to what was actually on the page.

Re-verify before editing or publishing any episode. Before you change an episode's prose, re-check every row in this file that episode relies on, because the product UI and pricing page change faster than a published guide does. A stale row here is worse than no row at all: it looks authoritative while being wrong.

Source priority when checking an Anthropic fact: support.claude.com articles first, for anything about claude.ai behaviour; then claude.com/pricing, for prices and plan comparisons; then platform.claude.com docs, for model names and API details; then anthropic.com/news, for launch announcements. Facts about a non-Anthropic product or agency (Episode 4) are checked against that organization's own official pages or the governing law. When two sources disagree, prefer whichever was updated more recently.
